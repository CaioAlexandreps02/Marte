# Marte

Jogo de colônia e automação em Marte, em primeira pessoa (Unity 6.3 URP), sobre o relevo **real** da cratera de
Jezero (28×25 km jogáveis, dados CC0 da USGS).

- [DECISOES.md](DECISOES.md) — decisões de design tomadas (D1–D14)
- [ROADMAP.md](ROADMAP.md) — ordem de trabalho até o MVP
- [HISTORICO.md](HISTORICO.md) — o que foi feito em cada sessão
- [CONHECIMENTO.md](CONHECIMENTO.md) — pesquisa e referências
- `design/` — mecânicas detalhadas
- `Simulation/` — lógica do jogo em C# puro (`dotnet test`)
- `Unity/` — projeto Unity ([Unity/README.md](Unity/README.md))
- `ferramentas/terreno/` — geração do terreno real ([README](ferramentas/terreno/README.md))
- `referencias/` — renders do terreno real de Jezero, estilo visual e imagens de trabalho
